Приложение 08 · Коран

Quran Guardians

Читайте Коран и учите его наизусть.

Бесплатное приложение для чтения Корана и заучивания его наизусть: с чтениями, кратким тафсиром, хадисами и временем намаза. Без рекламы, без учётной записи, без сбора данных. На восьми языках.

Заучивание по частям

Короткие части примерно по десять аятов: скрывайте слова, открывайте их касанием, затем проверяйте себя.

Тренируйтесь

Повторение, которое возвращается вовремя

Заученная часть возвращается на повторение через 1, 3, 7, 14, 30, 60 и 120 дней, а забытая — завтра.
